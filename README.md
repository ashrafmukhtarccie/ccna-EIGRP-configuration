

# EIGRP Configuration

## Overview

This lab demonstrates the configuration and verification of EIGRP as a dynamic routing protocol.

## Objectives

* Configure EIGRP
* Establish neighbor relationships
* Advertise networks
* Examine routing tables
* Verify connectivity

## Tools

* Cisco Packet Tracer
* Cisco IOS

## Outcome

Successfully configured EIGRP and established dynamic routing between networks.
